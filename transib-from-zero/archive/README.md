# Архив исследований Новосибирска

Содержимое перенесено из активной части проекта и не участвует в обычном
запуске или тестировании приложения.

## Скрипты и тесты

- `scripts/export_novosibirsk_research.py` формирует JSONL со списком объектов
  Новосибирска без описаний для внешнего исследовательского агента.
- `scripts/import_novosibirsk_research.py` проверяет подготовленный JSONL, а с
  флагом `--apply` импортирует проверенные справки и источники.
- `tests/` содержит тесты этих архивных скриптов.

Пример прежнего запуска из корня проекта:

Команды сохранены для справки: после переноса скрипты не являются частью
активного пакета `scripts` и не входят в обычный запуск проекта.

```powershell
python -B -m scripts.export_novosibirsk_research
python -B -m scripts.import_novosibirsk_research
python -B -m scripts.import_novosibirsk_research --apply
```

Для `--apply` после успешной проверки перезапустите backend:

```powershell
docker compose up -d --build backend
```

## Материалы

`agent_research_novosibirsk/` содержит инструкцию исследовательскому агенту,
границу Новосибирска, входные данные и сохранённый результат исследования.
Инструкция описывает формат JSONL, проверку источников и ограничения по
содержанию справок.
