Веб-сервис «Культурные места вдоль Транссиба» (Омск — Новосибирск).

## Как запустить

1. Установите Docker Desktop
2. Запустите Docker Desktop и дождитесь иконки кита в трее.
3. В терминале выполните:

    git clone https://github.com/XeN9GeN/West_Sib_GId.git
    cd transsib-culture
    docker compose up --build

4. Откройте http://localhost:8000/
